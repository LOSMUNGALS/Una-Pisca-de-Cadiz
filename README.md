# Una-Pisca-de-Cadiz

Este repositorio de este proyecto es un desorden, ya que esta lleno de partes que hemos trabajado, que despues lo combinamos en el codigo llamado CodigoFinal.py. Esto es lo que es cada uno:

- Tapas, Menu y Postres diccionarios: En este codigo, se puede encontrar todos los diccionarios, para las bebidas, descripciones de comida y toda la comida.
  
- Restaurant.py: Es nuestro sistema de elegir una mesa al empezar el codigo. Te pide si tienes reserva o no, y si tienes, pues le dices tu nombre y te deja pasar. Si le dices que no, tienes que elegir una mesa a ver si tiene cupo.
  
- Los 2 Menus: Estos son dos copias de nuestro menu que utilizamos para el proyecto del restaurante. Hay dos copias por errores ortograficos o generales en el diseño.
  
- ImageDisplayer.py: Este codigo fue utilizado para probar un sistema que te enseñaba una foto, y estabamos probandolo para enseñar el menu en vez de ponerlo en la terminal. Al final, terminamos no usando este sistema.
  
- Efectivo.py: Era un sistema que se uso para al final de ordenar todo lo que querias ordenar, pues te daba la opción de elegir para pagar en tarjeta o efectivo, y si elegias efectivo, te llevaba a este sistema.
  
- Codigo FInal.py: El codigo final que tiene parte de lo que hemos hablado aqui, más otras cosas como ordenar tu comida y el sistema de pago en tarjeta.
